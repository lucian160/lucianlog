How it works

One key connects your app to your logs.

You use the website to manage projects and investigate logs. Your application uses a project API key to send logs. That is the whole connection.

01

Create your account

Register, verify your email, and log in to the Lucian Logs website.

02

Create a project

Create one project for the application or service you want to monitor.

03

Connect with the key

Copy the project API key and store it securely on your application server.

04

Send and investigate

Your app sends logs to the API. They then appear in the project Dashboard and Logs pages.

Frequently asked questions

FAQ

What is the API key for?

It proves that an incoming log belongs to a specific project. Use it for server-to-server log submissions only.

FAQ

What protects the connection?

Use HTTPS, keep the key private, and rely on rate limiting, validation, and the optional firewall for additional protection.
