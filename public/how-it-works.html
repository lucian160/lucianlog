How it works

From your app to your dashboard.

Lucian Logs collects data from your services, stores it securely, and makes it easy to inspect later with filters, summaries, and dashboards.

01

Create a project

Log in, create a project, and get a unique API key for that app or service.

02

Send logs

Your application sends log events to the Lucian Logs API using the project key.

03

Store and organize

The server validates the key, stores the log data, and organizes it by project.

04

Monitor and fix

The dashboard shows recent activity so you can identify issues and respond faster.

Frequently asked questions

FAQ

Why do I need API keys?

They let each project securely authenticate its own log submissions without exposing shared credentials.

FAQ

Can I monitor uptime?

Yes. Use the health endpoint to monitor the app through tools like UptimeRobot or a custom checker.
